# DIRE-F Prototype — Digital Report Frontliner

Prototype mobile-first untuk:
- Splash Screen + tombol MULAI
- Home dengan 6 menu utama
- Register Frontliner (Save/Edit/Delete)
- Observasi 8 aspek (Complete=100, In Complete=50, No=50), catatan observasi, Save/Edit/Delete
- Daily Report (Semua Nama / Per Nama)
- Master Penilaian (24 item)
- Score Observasi + histori + review + improvement
- Cetak / Share

Data demo disimpan di localStorage browser.

## Menjalankan
Buka `index.html` di browser. Untuk Android, folder ini dapat dimasukkan ke project WebView/Capacitor/Cordova sebagai prototype.

Catatan: ini prototype front-end. Database server, login, AI, PDF generator, dan sinkronisasi cloud belum diaktifkan.
